# DPX — Supply Intelligence

**The world's most advanced AI-powered supply chain management platform.**

DPX is a micro-SaaS application that helps enterprises optimize their supply chains using cutting-edge artificial intelligence — reducing costs, preventing disruptions, and unlocking billions in operational value.

---

## 🚀 Features

- **AI Demand Forecasting** — Transformer-based models with 97.3% accuracy, predicting demand up to 18 months ahead
- **Real-Time Analytics** — Instant KPI visibility across the entire supply chain
- **Risk Intelligence** — Proactive detection of supplier, geopolitical, and climate risks
- **Automated Procurement** — AI negotiates and places POs based on configurable policies
- **Global Supplier Network** — Access 1.2M+ pre-vetted suppliers across 180 countries
- **Financial Optimization** — Dynamic inventory positioning to minimize carrying costs
- **Smart Alerts** — Intelligent notifications that surface only what matters
- **ERP Integration** — No-code connectors to SAP, Oracle, NetSuite and 50+ systems

## 📊 Platform Pages

| Page | Description |
|------|-------------|
| `/` | Marketing landing page with hero, features, pricing, and testimonials |
| `/dashboard` | Supply chain overview with live KPIs, demand charts, and AI alerts |

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Charts**: Recharts
- **Icons**: Lucide React
- **UI Components**: Radix UI

## 🏃 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the landing page.
Navigate to [http://localhost:3000/dashboard](http://localhost:3000/dashboard) for the app.
